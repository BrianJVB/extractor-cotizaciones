¿Cómo obtener ambas claves? (todo gratis, ~10 minutos)

① Google Client ID (Gmail + Sheets):

  1. Ve a console.cloud.google.com e inicia sesión.
  2. Crea un proyecto nuevo (ej: "Extractor Cotizaciones").
  3. Ve a APIs y Servicios → Biblioteca y activa: Gmail API y Google Sheets API.
  4. Ve a Credenciales → Crear → ID de cliente OAuth 2.0 → Aplicación web.
  5. En "Orígenes de JavaScript autorizados" agrega la URL donde alojarás este HTML.
  6. Copia el Client ID y pégalo arriba.
  7. En la pantalla de consentimiento OAuth, agrega los correos del equipo como usuarios de prueba.

② OpenRouter API Key (análisis con IA, gratis):

  1. Ve a openrouter.ai y crea una cuenta gratis.
  2. Ve a Keys → Create Key.
  3. Copia la clave (empieza con sk-or-v1-) y pégala arriba.
  4. Los modelos gratuitos no requieren tarjeta de crédito ni pago.
